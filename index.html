Experimental subset — not the Dart SDK

          
This project is a browser-only lexer, parser, and tree-walking interpreter. It is not a full Dart compiler, analyzer, or SDK implementation and does not claim full specification compatibility.

          
Implemented: basic declarations and literals, lists/maps/sets, functions and closures, interpolation for simple identifiers, arithmetic, assignments, if/switch, loops, and selected synchronous dart:io operations backed by IndexedDB.

          
Not implemented: static type analysis, Dart classes, full null safety, async/await and stream scheduling, most SDK libraries, complete Dart semantics, and many dart:io APIs. Unsupported features should report an explicit error.

          
The interpreter and all examples are bundled locally. The Android app needs no network connection to run.
